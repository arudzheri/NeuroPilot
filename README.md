# NeuroPilot: The Autonomous Study OS

NeuroPilot is a web application designed to help students organize their study materials, track progress, and navigate their learning efficiently. It provides an intuitive interface for managing courses, notes, and study schedules.

## Features
- Create, edit, and delete courses or subjects.
- Organize notes and resources for each course.
- Track study progress with visual indicators.
- Responsive design for desktop and mobile.
- Easy navigation between subjects and notes.

## Technologies Used
- **Front-end:** React.js, HTML, CSS, JavaScript
- **State Management:** (Redux, Context API)
- **Package Manager:** npm
- **Other Libraries:** (React Router, Axios)

## Installation & Setup
Follow these steps to run the project locally:

```sh
# Step 1: Clone the repository using the project's Git URL.
git clone https://github.com/arudzheri/neuropilot.git

# Step 2: Navigate to the project directory.
cd neuropilot

# Step 3: Install the necessary dependencies.
npm install

# Step 4: Start the development server with auto-reloading and an instant preview.
npm run dev
```
